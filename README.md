# CuidarBem

Aplicativo que conecta cuidadores, enfermeiras, contratantes e cursos de qualificação.

## Funcionalidades
- Cadastro e perfil de cuidadores , enfermeiras e contratante
- Busca e contratação de profissionais por contratantes
- Cursos para qualificação profissional
- Layout responsivo (mobile e computador)

## Tecnologias
- React Native (Expo) com TypeScript
- Hospedagem no Replit

## Como rodar
1. Clone o repositório: `git clone https://github.com/SEU_USUARIO/cuidarbem.git`
2. Instale as dependências: `npm install`
3. Inicie o projeto: `npx expo start`

## Variáveis de ambiente
Crie um arquivo `.env` com:
- `NOME_DA_VARIAVEL=`
